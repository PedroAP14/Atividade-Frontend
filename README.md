# Sistema de Gestão de Produtos

Aplicação web *full-stack* desenvolvida com **Angular** no frontend e **JSON Server** no backend para o gerenciamento (CRUD) de produtos, permitindo o controle de nome, data de validade e preço.

## 📁 Estrutura do Projeto

```text
├── Backend/
│   ├── db.json          # Base de dados JSON com a coleção de produtos
│   └── package.json     # Dependências e scripts da API
└── Frontend/
    ├── src/
    │   └── index.html   # Ponto de entrada da aplicação Angular
    └── package.json     # Dependências e configurações do Angular
